# games

Browser game builds and prototypes, one directory per game.

| Game | Description |
|---|---|
| [brotato-clone](brotato-clone/) | Brotato-style arena survival, vanilla JS |
| [claude-1shot-shiningforce](claude-1shot-shiningforce/) | Shining Force–style tactics RPG, one-shot build |
| [garden-defenders](garden-defenders/) | Tower defense campaign + arena mode (TypeScript/Vite) |
| [grok-1shot-game](grok-1shot-game/) | One-shot browser game |

Each directory keeps the full commit history of the standalone repo it came from.
